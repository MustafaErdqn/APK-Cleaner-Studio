# APK Cleaner Studio v0.6.1-dev.13

## Yerel HTTPS algılama düzeltmesi

- Özel IP adresi üzerinden başarıyla açılan HTTPS bağlantıları artık doğrudan güvenli kabul edilir.
- `https://10.x.x.x`, `https://192.168.x.x`, localhost ve güvenli alan adı bağlantılarında sertifika indirme kartı gizlenir.
- Sertifika kartı yalnızca sayfa HTTP üzerinden açıldığında gösterilir.

## Platform bilgisi

- Ana sayfadaki platform ifadesi `Windows + Termux + APK` olarak güncellendi.
