# APK Cleaner Studio v0.6.1-dev.2

Bu paket yalnızca test içindir ve kararlı v0.6.0 sürümünün yerine geçmez.

## Düzeltmeler

- Windows ve Termux arayüzü önce yerel HTTP adresinden açılır.
- HTTPS yükseltmesi yalnızca tarayıcı yerel sertifikayı gerçekten doğrulayabildiğinde yapılır.
- Güvenlik uyarısı elle geçilerek açılmış yerel HTTPS sayfası sertifika kurulumunu tamamlanmış saymaz.
- Ana sertifika kartı HTTP veya doğrulanmamış yerel HTTPS bağlantısında görünür.
- Yan paneldeki sertifika indirme bölümü kalıcı olarak korunur.
- Sertifika kartından yerel HTTP bağlantısına geri dönme bağlantısı sunulur.
- Üst çubuk daha görünür saydamlık, bulanıklık ve cam kenar yansımalarıyla yenilenir.
