# APK Cleaner Studio 0.6.0-dev.23

- Android ve Brave için bilgisayara özel yerel CA sertifikasını indirme ve güvenli kurulum yönergesi arayüze eklendi.
- CA indirme adresi, Android henüz HTTPS sertifikasına güvenmeden önce de yalnızca sertifika önyüklemesi amacıyla HTTP üzerinden erişilebilir.
- Masaüstündeki üçlü temel yetenek şeridi sağ panelin oluşturduğu boşluğa taşındı; ana çalışma sütunu kesintisiz bir içerik akışına dönüştürüldü.
