# APK Cleaner Studio 0.6.0-dev.17

Bu sürüm, paylaşılabilir paketlerin her bilgisayarda yalnızca kendi yerel uygulama adresini açmasını sağlar.

## Başlangıç adresi

- Windows uygulaması açıldığında tarayıcı doğrudan `http://127.0.0.1:8080/` adresini açar.
- Özel Keenetic alan adına otomatik geçiş ve yerel ağ istemcilerini bu adrese zorla yönlendirme kaldırıldı.
- Keenetic üzerinden elle yapılan dış erişim çalışmaya devam eder; yalnızca uygulamanın başlangıç hedefi değildir.
- Başka kullanıcılara dağıtılan kopyalar sahibinin özel HTTPS adresini açmaz.

## Masaüstü yerleşimi

- Dev.16’da eklenen, boş başlangıç ekranındaki sol çalışma kartının sağ panel yüksekliğine uyum sağlaması korunmuştur.
