# APK Cleaner Studio 0.6.0-dev.3

Bu test sürümü yalnızca arayüz düzeltmelerini içerir. Motor sürümü `2.0-dev.1` olarak korunmuştur.

- Masaüstü işlem adımlarındaki çizgi ve metin çakışması giderildi.
- Mimari ve dil bileşeni kartları kompakt ölçüye alındı.
- Mobilde bileşen kartları iki sütunlu, daha verimli düzene geçirildi.
- Koyu temadaki seçili durum korunurken gereksiz büyük vurgu azaltıldı.
- Hareketli ana başlığın alanı sabitlendi; geçiş süresi yumuşatıldı ve sayfa kayması önlendi.
- Stabil sürüm ile önceki geliştirme paketleri değiştirilmedi.
