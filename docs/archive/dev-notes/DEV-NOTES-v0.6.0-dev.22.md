# APK Cleaner Studio 0.6.0-dev.22

- Yerel sunucu aynı `8080` bağlantı noktasında HTTP isteklerini HTTPS’e yükseltir ve doğrudan TLS bağlantılarını kabul eder.
- Windows’ta cihaza özel yerel sertifika üretilir. Mevcut kullanıcı güven deposuna ekleme işlemi yalnızca ilk açılışta gösterilen açık onaydan sonra yapılır; özel anahtar cihazdan çıkmaz.
- Masaüstü başlangıç alanı küçük kart yığınları yerine tek, bütünlüklü bir yerel işlem özeti ve süreç rotasıyla yeniden tasarlandı.
- Masaüstündeki adım daireleri ve bağlantı çizgileri ekran ölçeklendirmesinde daha düzgün görüntülenecek şekilde tam piksel çizimine geçirildi.
