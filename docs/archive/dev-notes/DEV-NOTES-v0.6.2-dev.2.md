# APK Cleaner Studio v0.6.2-dev.2

Bu paket, kararlı v0.6.1 sürümünün yerini almayan ikinci 0.6.2 test yapısıdır.

## Deneme kapsamı

- Sonuç ve geçmiş işlem raporları indirilmeden uygulama içindeki temalı pencerede görüntülenir.
- Android çıktı kaydetme bildirimi `Çıktı kaydedildi` olarak düzeltildi.
- Mobil yatay görünümde başlık tipografisi mobil düzenle eşitlendi.
- Android yatay görünümünde arka plan kamera çentiğine kadar uzatıldı; etkileşimli üst çubuk güvenli alanda tutuldu.
- Temizlenen APK çıktıları bütün platformlarda yalnızca `CN=APK Cleaner Studio` kimliğini taşıyan ortak sertifikayla imzalanır.
- Önceki dev.1 düzeltmeleri; RES çözümü, ilk geçiş XML denetimi, işlem odağı, iptal ve modern onay pencereleri korunur.

Android test paketi kararlı uygulamayla yan yana kurulabilmesi için `com.apkrepo.apkcleanerstudio.dev` paket adını kullanır.
