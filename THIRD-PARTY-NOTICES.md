# Third-party tools

APK Cleaner Studio can bundle or download these tools and libraries:

- Google DexLib2 — BSD 3-Clause — https://github.com/google/smali/tree/main/dexlib2
- Direct DEX Patcher — project source; links only against the required DexLib2 runtime classes and edits normal DEX instructions in place
- APKEditor — Apache License 2.0 — https://github.com/REAndroid/APKEditor
- Uber APK Signer — Apache License 2.0 — https://github.com/patrickfav/uber-apk-signer
- Eclipse Temurin JRE — GPLv2 with Classpath Exception — https://adoptium.net/
- Material Design `language` icon — Apache License 2.0 — https://github.com/google/material-design-icons
- Telegram logo — Telegram brand asset — https://telegram.org/

The tools remain the property of their respective authors and are used according to their project licenses.
