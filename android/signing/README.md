# Android yayın anahtarı

Yayın anahtarları ve parola içeren `signing.properties` kaynak ağacında tutulmaz.

Varsayılan özel konum:

`%LOCALAPPDATA%\APKCleanerStudio\release-signing`

Başka bir konum kullanmak gerekirse `APK_CLEANER_SIGNING_PROPERTIES` ortam değişkeniyle dışarıdaki properties dosyasının tam yolu verilir. Bu klasörü herkese açık depolara yükleme; güvenli ve şifreli bir yedeğini ayrıca sakla.
